# Símbolos das tecnologias

Sete vetores vêm do [Simple Icons](https://github.com/simple-icons/simple-icons), commit `98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d`. A licença da coleção CC0-1.0 está preservada em `LICENSE.md`; ela não substitui licenças específicas dos desenhos originais nem regras de marcas. PostgreSQL usa o SVG de três cores publicado pela própria comunidade, sem alteração do desenho ou das cores. Todos são arquivos locais; não há requisições externas ao renderizar.

O uso é identificativo dos cursos, sem afiliação ou endosso. As marcas pertencem aos respectivos titulares. Os vetores Simple Icons não são apresentados como arquivos oficiais. Neles foi acrescentado somente `fill` identificativo; nenhuma moldura foi incorporada. Consulte também o [disclaimer da coleção](https://github.com/simple-icons/simple-icons/blob/98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d/DISCLAIMER.md).
