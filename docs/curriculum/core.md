# Backend Engineering Core

This is a deliberately bounded curriculum, not a catalog of all software engineering. Its seven areas are:

0. Execution
1. State
2. Concurrency
3. Asynchronous Work
4. Load & Performance
5. Failure & Reliability
6. Distribution

**Observability** spans every area from Lab 001. **Security** will develop progressively in later labs.
